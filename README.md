# Gliph-ui

Modern UI Components for React Native & Flutter

Gliph-ui is a cross-platform UI component ecosystem focused on building beautiful, reusable, animated, and production-ready components for React Native and Flutter developers.

---

## Features

- Modern mobile UI components
- Smooth animations
- Glassmorphism support
- Cross-platform architecture
- React Native support
- Flutter support
- TypeScript support
- Developer-friendly APIs
- Production-ready components

---

## Components

Current and upcoming components:

- Elastic Slider
- Calendar Picker
- Scroll Picker
- Bottom Sheet
- Glass Cards
- Animated Buttons
- Progress Indicators
- Charts & Graphs
- Input Components
- Modal Systems

---

## Installation

### React Native

```bash
npm install gliph-ui
```

or

```bash
yarn add gliph-ui
```

---

### Flutter

```yaml
dependencies:
  gliph_ui: latest_version
```
